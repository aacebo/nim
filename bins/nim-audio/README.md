# Audio

working memories.

## Responsibilities

- Consumes `nim.audio.artifact.create`.
- Captions and classifies audio; embeds and categorizes annotations.
- Creates or updates a linked working memory.
- Emits `nim.artifact.create`, `nim.artifact.analyze`, and `nim.memory.{create|update}`.
